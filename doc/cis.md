# AutoTool 企業 CIS 視覺規範

版本：v1.0  
更新日期：2026-05-20  
適用範圍：AutoTool 官方網站、簡報、社群素材、銷售文件、系統介面

## 1. 品牌定位與視覺語言

### 1.1 品牌定位

- 品牌角色：企業自動化小工具與流程優化服務提供者。
- 核心價值：效率、可靠、務實、可快速落地。
- 溝通語氣：專業但不生硬，簡潔、有溫度、偏顧問式。

### 1.2 視覺關鍵字

- 沉穩可信
- 乾淨俐落
- 科技感但不冰冷
- 高可讀性與高資訊密度平衡

## 2. 品牌色彩系統

### 2.1 主色與輔色

- Primary 主色：#004E5B（深藍綠）
- Secondary 輔色：#E2BCB8（柔和粉膚）
- Accent 強調色：#FF6B6B（提醒、重點 CTA）

### 2.2 中性色

- 深文字色：#333333
- 次文字色：#666666
- 邊框色：#E0E0E0
- 淺背景色：#F5F5F5
- 白底色：#FFFFFF

### 2.3 色彩使用比例

- 建議比例：主色 60%、中性色 30%、輔色與強調色 10%。
- 主色用於：品牌識別、主要按鈕、導覽重點、標題裝飾。
- 輔色用於：區塊背景、標籤、卡片點綴。
- 強調色用於：警示、關鍵行動按鈕、重要數據高亮。

### 2.4 對比與可讀性

- 正文與背景對比至少達 WCAG AA（建議 4.5:1 以上）。
- 避免使用輔色文字直接放在白底大段內文。
- 強調色不作為長段內文主文字色。

## 3. 字體系統

### 3.1 字型家族

- 中文主字體：Noto Sans TC
- 英文強調字體：Poppins
- 系統預設備援：sans-serif

### 3.2 字重規範

- Heading：700 或 900
- 內文：400 或 500
- 按鈕與標籤：500 或 600

### 3.3 字級階層（建議）

- H1：48px / 1.3
- H2：36px / 1.35
- H3：28px / 1.4
- H4：22px / 1.4
- Body L：18px / 1.7
- Body M：16px / 1.6
- Body S：14px / 1.6
- Caption：12px / 1.5

### 3.4 文字使用原則

- 全站介面文字使用繁體中文（zh-TW）。
- 標題避免過長，建議單行 14 至 24 字。
- 內文每行建議 28 至 40 個中文字，避免閱讀疲勞。

## 4. Logo 規範

### 4.1 Logo 版本

- 標準版：Logo 圖像 + AutoTool 字標。
- 純字標版：僅 AutoTool 字標。
- 單色版：全深色或全白色版本。

### 4.2 最小尺寸

- 數位畫面最小寬度：120px。
- 社群頭像或 favicon 可使用簡化圖像版。

### 4.3 安全留白

- Logo 四周至少保留 1x 安全距離（x 為 Logo 主圖形高度的 1/4）。
- 不得讓其他文字、圖示、邊框侵入安全留白區。

### 4.4 禁止事項

- 不得任意改色、拉伸、旋轉、加描邊或陰影。
- 不得將 Logo 疊加於低對比複雜背景。
- 不得拆分 Logo 元件後重新排列。

## 5. 版面與間距系統

### 5.1 容器與斷點

- 最大內容寬度：1200px。
- Desktop：1024px 以上。
- Tablet：768px 至 1023px。
- Mobile：767px 以下。

### 5.2 間距 Token

- XS：0.5rem
- SM：1rem
- MD：1.5rem
- LG：2rem
- XL：3rem
- 2XL：4rem

### 5.3 版面原則

- 區塊上下留白至少 XL。
- 卡片內距至少 MD。
- 元件與元件間距優先使用 SM 至 LG，避免硬寫數值。

## 6. 形狀、圓角、陰影

### 6.1 圓角系統

- Small：8px
- Medium：12px
- Large：16px

### 6.2 陰影系統

- Shadow SM：0 2px 8px rgba(0, 78, 91, 0.08)
- Shadow MD：0 4px 12px rgba(0, 78, 91, 0.12)
- Shadow LG：0 8px 24px rgba(0, 78, 91, 0.15)

### 6.3 動態轉場

- 統一轉場：all 0.3s ease-in-out
- Hover 與 Focus 需一致，不可只做 Hover。

## 7. 元件視覺規範

### 7.1 按鈕

- Primary Button：主色底 + 白字。
- Secondary Button：白底 + 主色邊框 + 主色字。
- Accent Button：強調色底 + 白字，限重要行動。
- 圓角：建議使用 12px。
- 最小高度：44px（符合觸控友善）。

### 7.2 卡片

- 背景：白色或淺灰。
- 邊框：可用 #E0E0E0 1px，或使用陰影取代。
- 圓角：12px 或 16px。
- Hover：輕微上浮與陰影增強，不超過 6px 位移。

### 7.3 導覽列

- 固定於頂部。
- 背景維持白色，滾動時可套用陰影提升層次。
- 目前頁面高亮色為主色，並搭配底線動畫。

### 7.4 表單

- 輸入框高度建議 44px 以上。
- 邊框預設 #E0E0E0，Focus 改為主色。
- 錯誤訊息可使用 Accent 色並附文字說明。

## 8. 影像與圖示規範

### 8.1 影像風格

- 偏向真實工作情境：辦公、協作、流程、自動化。
- 色調以中性偏暖為主，避免過度飽和與過暗。
- 優先選擇留白足夠、可疊標題的照片。

### 8.2 圖示風格

- 使用 Font Awesome 6。
- 同一畫面使用同系列、同粗細圖示。
- 圖示色彩優先主色，次要資訊可用次文字色。

## 9. 文案與語言風格

### 9.1 語言規範

- 預設語系為繁體中文（zh-TW）。
- 專有名詞第一次出現可中英並列，後續統一其中一種。
- 避免過度技術術語堆疊，以商業價值為主軸。

### 9.2 標點與格式

- 中文使用全形標點。
- 英文與數字前後留半形空格（例：導入 3 個流程）。
- CTA 文案使用動詞開頭，字數控制在 4 至 10 字。

## 10. 響應式與無障礙

### 10.1 響應式原則

- 手機版優先確保：可讀、可點、可捲動。
- 重要 CTA 在手機版需保持首屏可見或快速可達。
- 導覽選單展開後需可清楚關閉。

### 10.2 無障礙原則

- 所有互動元件需具備鍵盤焦點樣式。
- 圖片必填替代文字（alt）。
- 不以顏色作為唯一資訊傳遞方式。

## 11. 實作對應（Design Token）

以下為前端實作統一來源，需與樣式檔同步維護：

```css
:root {
  --primary-color: #004e5b;
  --secondary-color: #e2bcb8;
  --accent-color: #ff6b6b;
  --dark-bg: #f5f5f5;
  --light-bg: #ffffff;
  --text-dark: #333333;
  --text-light: #666666;
  --border-color: #e0e0e0;

  --font-heading: "Noto Sans TC", sans-serif;
  --font-body: "Noto Sans TC", sans-serif;
  --font-accent: "Poppins", sans-serif;

  --spacing-xs: 0.5rem;
  --spacing-sm: 1rem;
  --spacing-md: 1.5rem;
  --spacing-lg: 2rem;
  --spacing-xl: 3rem;
  --spacing-2xl: 4rem;

  --border-radius-sm: 8px;
  --border-radius-md: 12px;
  --border-radius-lg: 16px;

  --shadow-sm: 0 2px 8px rgba(0, 78, 91, 0.08);
  --shadow-md: 0 4px 12px rgba(0, 78, 91, 0.12);
  --shadow-lg: 0 8px 24px rgba(0, 78, 91, 0.15);

  --transition: all 0.3s ease-in-out;
}
```

## 12. 維護流程與版本控管

- 本文件為 CIS 單一事實來源，更新後需同步檢查網站樣式。
- 任何顏色、字型、間距調整，需先更新本規範再改程式。
- 建議每季檢視一次實際素材一致性（網站、社群、提案簡報）。
